- `run()` builds the ordinary Tauri application with explicit plugins, including exactly one Tauri updater plugin registration for Rust `UpdaterExt`, plus managed state. Its `invoke_handler` retains an explicit `generate_handler!` allowlist; the frontend uses the custom Rust IPC façade and receives no updater-plugin capability permission.
- The independent review confirmed the readiness/check/request command names match the frontend API and `{ expectedVersion }` maps to Rust `expected_version`. [`check-tauri-command-registration.mjs`](../scripts/check-tauri-command-registration.mjs) verifies the complete frontend/Rust command-name set and the exact reviewed `lib.rs` checkpoint. This is a name-set check, not an authorization review of every handler or proof that the allowlist is historically complete. The source baseline is owner-confirmed; the base Tauri config remains updater-disabled, while the owner authorized early-access release builds with the configured production key. Live GitHub redirect/proxy and cancellation/concurrency/repair acceptance remain documented risks, not completed tests.
- The inspected setup wires tray actions to the shared mode application, starts statistics after setup, supports the explicit `--silent` hide path, and hides on close only when close-to-tray is configured. Exit handling attempts to restore process scheduling and foreground priority snapshots.
- Daily log pruning is limited to regular files with the AeroTune date-suffixed log name and a 14-day age threshold.
- This source-level review plus passing compilation/contracts can detect some structural regressions, but cannot detect behavior omitted during reconstruction or verify all runtime paths on supported Windows versions.

2. Compare the complete `lib.rs`, not just command names. The incremental WinGet change has an independent review covering module declaration, handler allowlist, command implementation boundary, and unchanged Tauri capabilities/plugins; future changes require the same review.
3. Re-run the command-registration and release-contract suites; review authorization in the corresponding Rust handlers and exercise startup, tray, UAC, shutdown, and standard updater install/cancel/interruption behavior in the local Windows installation.
4. Record the owner-confirmed source baseline, release commit/tree digest, full diff, reviewer(s), findings, and sign-off. The local fingerprint remains an IPC integrity checkpoint, not proof of authorship.
5. Keep release readiness blocked until the real Minisign key, bounded GitHub transport, system-proxy review, and local Windows/UAC acceptance gates pass. The standard Tauri updater has no AeroTune protected-staging or crash-safe rollback subsystem.
